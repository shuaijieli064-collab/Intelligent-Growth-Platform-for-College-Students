# 本机启动指南

## 一、GUI 桌面版（最简单）

双击项目根目录的 **`启动.bat`** 即可。

它会自动：启动 MySQL → 初始化数据库 → 打开桌面应用。

> 首次运行前，先双击 **`一键安装.bat`** 安装 Python 依赖。

---

## 二、Web 版（浏览器访问）

### 方式 A：一键启动（推荐）

双击项目根目录的 **`启动Web.bat`** 即可。

它会自动开两个窗口：后端 API（端口 8000）+ 前端（端口 5173）。**两个窗口都不要关。**

完成后浏览器访问 **http://localhost:5173**。

### 方式 B：手动分步启动

需要开两个终端窗口。

#### 第 1 步：启动后端

在项目根目录打开终端：

```bash
python -m web.main
```

看到 `Uvicorn running on http://0.0.0.0:8000` 就说明后端起来了。**这个窗口不要关。**

#### 第 2 步：启动前端

另开一个终端，进入 frontend 目录：

```bash
cd frontend
npm run dev
```

看到 `Local: http://localhost:5173` 就说明前端起来了。**这个窗口也不要关。**

#### 第 3 步：打开浏览器

访问 **http://localhost:5173** 即可使用。

---

## 三、首次运行前的准备（只需做一次）

### 1. 安装 Python 依赖

```bash
pip install -r requirements.txt
pip install -r requirements-web.txt
```

### 2. 安装前端依赖

```bash
cd frontend
npm install
```

### 3. 确保 MySQL 在运行

如果 MySQL 没启动，`启动.bat` 会自动拉起。手动启动可以：

```bash
python 启动.py
```

### 4. 初始化数据库（如果还没建过）

```bash
python scripts\init_database.py
```

| 启动桌面版 | 双击 `启动.bat` |

| 启动 Web 后端 | `python -m web.main` |

| 初始化数据库 | `python scripts\init_database.py` |
| 生成演示数据 | `python scripts\generate_mock_data.py` |
