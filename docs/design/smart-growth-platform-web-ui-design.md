# 大学生智能成长平台 — Web 前端界面设计稿计划

## Summary

为"大学生智能成长平台"（现有 PyQt5 桌面应用）设计完整的 Web 前端界面设计稿（.design 画布项目），使用 Claude 设计系统作为风格约束，覆盖全部 12 个功能模块。设计稿将作为后续 React + TypeScript 开发的视觉规范和组件参考。

## Current State Analysis

**现有系统**：基于 Python 3.12 + PyQt5 的桌面应用，三层架构（表现层/业务层/数据层），包含 12 个功能模块，使用 MySQL 8.4 数据库。

**已有设计基础**：
- 桌面端已建立 Claude 风格的双主题系统（暖白浅色 + 暖炭深色），定义在 `presentation_layer/styles.py`
- 已有完整的 PRD 文档（`.trae/specs/desktop-to-web-migration/spec.md`）和任务拆分（`tasks.md`）
- FastAPI 后端骨架已搭建（`web/main.py`），但前端尚未开发
- Claude 设计系统已安装，包含完整的颜色 token、字体、组件规范和 UI Kit 参考页面

**核心问题**：缺少 Web 端的视觉设计稿，开发团队没有明确的界面设计规范可参照。

### 步骤 1：确认设计风格

使用 Claude 设计系统（library-bound 模式），直接提取设计约束，跳过风格选择流程。

**Claude 设计系统核心参数**：
- 品牌色：`#d97757`（温暖赤陶橙）
- 字体：Poppins（UI）/ Newsreader（标题）/ Lora（正文）/ Geist Mono（数据）
- 圆角：8px / 12px / 16px / 20px / 24px
- 阴影：双层微透明（0.05-0.25）
- 间距基线：4px

**领域扩展色**（Claude 设计系统未覆盖，需自定义）：
- Warning（需关注）：`#d97706`，用于健康度 60-80、进行中状态
- 桌面端原有语义色（success/error）可直接映射到 Claude 的 success/error token

### 步骤 3：设计整体布局框架

**布局结构**：左侧 230px 固定侧边栏 + 右侧主内容区

**侧边栏设计**：
- 品牌标识区：brand-mark 方块 + "智能成长平台"
- 学生切换器：放在品牌标识下方
- 12 个导航项按 4 组分区（概览/学习/监测/分析）
- 底部：主题切换按钮
- 图标方案：Lucide 线性图标，替换桌面端的 emoji
- 交互状态：默认/悬浮/选中（左侧 3px 品牌色指示条）

**Topbar 设计**：
- 左侧：当前学生信息（头像 + 姓名 + 学号）
- 右侧：主题切换按钮
- 背景：半透明模糊效果（`backdrop-blur`）
- `sticky` 定位

**响应式断点**：
- `>= 1024px`：230px 侧边栏 + 正常内容区
- `768px - 1023px`：64px 图标侧边栏 + 全宽内容
- `< 768px`：隐藏侧边栏，汉堡菜单触发抽屉

**参考源**：Claude 设计系统 `ui_kits/website/index.html` 的布局结构；桌面端 `main_window.py` 的 NAV_ITEMS 列表

## Assumptions & Decisions

1. **全部 12 个模块都设计**：采用分级详细度策略（5 全面 + 5 标准 + 3 概设），平衡覆盖面与执行效率
2. **深色主题不单独设计页面**：Claude 设计系统已包含完整深色 token，在 Shell 框架画布中添加主题对照标注即可
3. **数据录入只完整设计 2 个代表性 Tab**：学习记录（表单范式）+ 课程管理（列表范式），其余标注复用说明
4. **图标使用 Lucide 线性风格**：与 Claude 设计系统 asset 风格一致，需补充 5 个导航图标
5. **画布尺寸统一 1440x900px**：Desktop 基准视口，响应式行为通过标注说明
6. **图表区域使用占位设计**：在画布中用带标注的占位区域表示，附 ECharts 配色和样式说明
7. **导航项保持桌面端原有顺序和分组逻辑**：按"概览/学习/监测/分析"四组分类
